\begin{abstract}
The Calculator App is designed to solve basic linear equations.
It allows users to enter an equation and displays the value of
the unknown variable. The system provides a simple and quick way
to solve equations and handles invalid input with an error message.
\end{abstract}

\section{Introduction}

The Calculator App is designed to solve basic linear equations.
It allows users to enter an equation and displays the value of
the unknown variable.

\section{Purpose}

The purpose of the application is to provide a simple and quick
method for solving basic linear equations.

\section{Scope}

The system supports linear equations containing one unknown
variable. It accepts an equation, processes it, and displays
the solution.

\section{Basic Functionality}

The application will:

\begin{itemize}
    \item Accept a linear equation from the user.
    \item Identify the unknown variable.
    \item Calculate its value.
    \item Display the result.
    \item Show an error for invalid input.
\end{itemize}

\section{Requirements}

The system shall allow users to enter and solve basic linear
equations. It shall process the equation and display the
calculated value of the unknown variable.

The system shall also detect invalid or unsupported equations
and display an error message.

\section{Examples}

The application should solve equations such as:

\begin{itemize}
    \item $2x + 5 = 15$
    \item $3x - 4 = 11$
    \item $5x = 25$
    \item $x + 7 = 12$
\end{itemize}

\section{User Requirements}

The user should be able to enter an equation easily and view
the calculated answer clearly.

\section{System Requirements}

\subsection{Hardware Requirements}

\begin{itemize}
    \item Computer or suitable device
    \item Display screen
\end{itemize}

\subsection{Software Requirements}

\begin{itemize}
    \item Supported operating system
    \item Required software environment
\end{itemize}

\section{Error Handling}

The system should display an error when the entered equation
is invalid or unsupported.

\section{Conclusion}

The Calculator App provides a simple way to solve basic linear
equations. This document describes its main functionality and
initial requirements.
